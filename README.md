# Rishith Manchala — Personal Site

Hey, this is my personal portfolio site.

It is a single page portfolio site which was intricately designed with a variety of features and my photo too.

## What's inside

The site opens with a intro animation of my logo and also my name on the screen.

- **Hero** — It is a big name, then comes a link to [Yuvora](https://yuvora.org), and a small tag line *Design & Develop*.
- **About** — it is a a short intro of me rishith  and also a photo of mine.
- **Projects** — It conatins Scholarstock, CS School Sync, Yuvora, IRIS, and Solar Saathi, each with links to the code and a live demo where one exists.Bascially in short all of tehm are my proejcts.
- **Contact** —They contain my  email, GitHub, and Slack.

There are a few extra touches if you poke around: a custom cursor ring, glassy cards, and a canvas behind everything where particles slowly drift into the shape of my portrait, react to your mouse, and scatter when you get close.
